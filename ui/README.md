# UI GEMEROTIC

Frontend del constructor visual OT/IT de GEMEROTIC.

## Stack

- React
- TypeScript
- Vite
- React Flow (`@xyflow/react`)
- Lucide React
- Vitest

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run test:run
npm run build
```

La UI debe emitir payloads compatibles con `TopologyCreate` y persistirlos
mediante `POST /api/v1/topology`.
