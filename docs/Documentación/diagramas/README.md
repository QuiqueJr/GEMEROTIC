# Diagramas del TFM

Esta carpeta contiene las fuentes editables de los primeros diagramas conceptuales del TFM.

- `arquitectura_global.mmd`: flujo general de GEMEROTIC con contexto AMC, PostgreSQL granular, outbox y runtime.
- `modelo_tres_capas.mmd`: separación física, lógica y seguridad OT.
- `flujo_topologycreate.mmd`: transformación del estado visual al contrato formal.
- `pipeline_validacion.mmd`: persistencia, outbox, generación de artefactos, runtime y evidencias de validación.

En próximas iteraciones se pueden exportar a PNG/SVG con Mermaid CLI o rehacer en Excalidraw para conseguir un estilo más visual. Las capturas reales de UI, NetBox y resultados se incorporarán cuando el prototipo esté estabilizado.
