# Plugin `netbox_ot_security`

Plugin de NetBox para modelar la capa de seguridad OT de GEMEROTIC dentro del
SSoT.

## Objetivo

Persistir en NetBox los objetos de Layer 3 definidos por GEMEROTIC:

- Zonas IEC 62443
- Conductos entre zonas
- Niveles Purdue
- Security Levels

## Estado

Versión inicial enfocada en:

- Modelos persistentes
- API REST del plugin
- Compatibilidad con NetBox `4.5.x`
